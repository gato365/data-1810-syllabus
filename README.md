# STAT/DATA 1810 syllabus

This repository contains the source material and static website for the STAT/DATA 1810 course syllabus.

The published site is built directly from [`syllabus_website/`](syllabus_website/). Update `syllabus_website/syllabus.yaml.js`, commit, and push to `main`; the GitHub Pages workflow will publish the change automatically.

## Preview locally

Open `syllabus_website/index.html` in a browser. No build step or local server is required.
